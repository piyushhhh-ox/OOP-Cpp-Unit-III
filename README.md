## Programs

| No. | Program                               | Description                                                                      |
| --- | ------------------------------------- | -------------------------------------------------------------------------------- |
| 1   | Function Overloading                  | Demonstrates compile-time polymorphism using overloaded functions.               |
| 2   | Area Calculator                       | Calculates areas using function overloading with different parameters.           |
| 3   | Unary Minus Operator                  | Demonstrates unary operator overloading using the minus operator.                |
| 4   | Prefix and Postfix Increment          | Demonstrates prefix and postfix increment operator overloading.                  |
| 5   | Complex Number Addition               | Demonstrates binary `+` operator overloading for complex numbers.                |
| 6   | Distance Comparison                   | Demonstrates relational operator overloading for comparing distances.            |
| 7   | Friend/Non-member Operator            | Demonstrates operator overloading using a friend function.                       |
| 8   | Base Pointer Without Virtual Function | Demonstrates static binding using a base-class pointer.                          |
| 9   | Base Pointer With Virtual Function    | Demonstrates run-time polymorphism using a virtual function.                     |
| 10  | Base Reference With Virtual Function  | Demonstrates dynamic binding using a base-class reference.                       |
| 11  | Abstract Class                        | Demonstrates pure virtual functions and abstract classes.                        |
| 12  | Collection of Shape Pointers          | Demonstrates polymorphic processing using shape pointers.                        |
| 13  | Virtual Destructor                    | Demonstrates correct destruction through a base-class pointer.                   |
| 14  | Object Slicing                        | Demonstrates object slicing and how references preserve polymorphism.            |
| 15  | Payment Processing System             | Demonstrates a real-world payment system using run-time polymorphism.            |
| 16  | Employee Payroll Mini-Project         | Demonstrates an employee payroll system using abstract classes and polymorphism. |
